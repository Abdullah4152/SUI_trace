# Anonymization Notes

This artifact has been prepared for anonymous peer review.

## Removed Or Generalized

- Author names and affiliations are not included.
- Local Windows paths are not included in reviewer-facing commands.
- Personal Kaggle dataset paths are replaced by generic placeholders.
- NVIDIA API key names are generic placeholders: `NVIDIA_API_KEY_1` through `NVIDIA_API_KEY_8`.
- Human raters are anonymized as `R1`, `R2`, and `R3`.

## Preserved

- Model identifiers are preserved because they are necessary for reproduction.
- Benchmark names are preserved because they are necessary for interpretation.
- Human annotation labels are preserved, with anonymized rater ids, because they cannot be regenerated by running the pipeline.

## Not Distributed

Generated model outputs, summary files, and paper tables are not included in this artifact.
They are produced by running the pipeline. This removes a class of anonymity risk as a side
effect: raw model outputs and long reasoning traces are the most likely place for an
identifying artifact — a local path, a prompt fragment, a stray filename — to survive a manual
review.

## Manual Check

Before uploading to an anonymous repository, run:

```bash
grep -RniE "author|affiliation|@|C:\\\\|Users|downloads|<personal-username>|api[_-]?key\\s*=" .
```

On Windows PowerShell:

```powershell
rg -i "author|affiliation|@|C:\\\\|Users|downloads|<personal-username>|api[_-]?key\\s*=" .
```

Expected benign matches:

- Generic API key environment variable names.
- This anonymization checklist itself.
- Model/provider names.

There should be no actual API keys, names, emails, or local user paths.
